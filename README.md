# Asterward calendar feeds

This repository publishes subscribable `.ics` calendars through GitHub Pages.
Each calendar shows up as its own calendar in Outlook, Apple Calendar or Google Calendar, and refreshes automatically.

This repository is public. Never put booking references, account numbers or other private details in a feed.

## Subscribe

**Outlook:** choose **Calendar**, then **Add calendar**, then **Subscribe from web**.
Paste the subscription URL and give the calendar a name.

**Apple Calendar (iPhone, iPad, Mac):** open the URL with `webcal://` in place of `https://`, for example
`webcal://akumarau.github.io/asterward-calendar-feeds/milky-way-2027.ics`.
On iPhone you can also go to **Settings**, then **Calendar**, then **Accounts**, then **Add Subscribed Calendar**.

**Google Calendar:** on the web, choose **Other calendars**, then **+**, then **From URL**, and paste the `https://` URL.
Google refreshes subscribed calendars slowly, often only every 12 to 24 hours.

Subscribed calendars are read only. Make changes here, and calendar apps pick them up within a few hours.

## Hand built calendars

Each hand built calendar has a Python generator in `calendars/` that writes its feed into `docs/`.

To change one:

1. Edit the events in the generator, for example `calendars/japan_2026.py`.
2. Run `python calendars/japan_2026.py`.
3. Commit the generator and the updated file in `docs/`.

Keep event UIDs stable so Outlook updates events instead of duplicating them.

To add a new calendar, copy an existing generator, change the output file name and the events, then add a row to the table above.

## Astro calendars 2027

Two photography planning feeds for Sydney and NSW, built for a Sony A1 kit and a Sky-Watcher Esprit 80ED setup.
Every event carries the details needed for later research in the field.

* **What:** the subject, the composition and the priority.
* **When:** shoot window, best moment, sunset, twilight and moon times in Sydney time.
* **Where:** a camera pin and a subject pin as Google Maps links, with distance and bearing.
* **Sky:** core or moon altitude and azimuth through the session.
* **Kit:** lens choice, framing and starting settings.
* **Tides:** for coastal events, BOM 2027 high and low waters from the nearest standard port, the height at the key moment, and a caution when a rock platform is under water.
* **Field notes:** access, gates and safety.
* **Verify:** a prefilled TPE Web link (camera pin, subject pin and time) and PhotoPills steps.
* **Sources:** where every number came from.

Calendar alerts fire 2 days before (weather check) and 3 hours before (leave).

### Rebuild the astro feeds

```bash
pip install -r calendars/requirements-astro.txt
python calendars/milky_way_2027.py
python calendars/full_moon_2027.py
```

Tide data lives in `calendars/data/bom_tides_2027.json`, parsed from the BOM 2027 NSW tide table PDFs for Newcastle, Fort Denison and Port Kembla.
To refresh it, run `pip install pdfplumber` and then `python calendars/bom_tides.py`.

The first run downloads the JPL DE421 ephemeris (about 17 MB) into `calendars/`. It is git ignored.
Sites, subjects and field notes live in the `NIGHTS` and `PLAN` lists at the top of each generator.
All sky numbers are recomputed on every run.

### Method and sources

* Moon phases match the US Naval Observatory 2027 table: https://aa.usno.navy.mil/calculated/moon/phases?year=2027
* Sun, moon and galactic core positions come from Skyfield with JPL DE421, with standard refraction (`calendars/astro_engine.py`).
* Site coordinates come from OpenStreetMap. Ground heights and terrain horizons come from SRTM 30 m via OpenTopoData.
* Landmark heights are approximate. Check each shot in TPE Web or PhotoPills before you travel.
* TPE Web link format follows the TPE URL parameter guide: https://photoephemeris.com/en/help/general/tpe-url-parameters
* Tide predictions come from the Bureau of Meteorology 2027 NSW tide tables: [Newcastle](https://www.bom.gov.au/ntc/IDO59001/IDO59001_2027_NSW_TP004.pdf), [Port Kembla](https://www.bom.gov.au/ntc/IDO59001/IDO59001_2027_NSW_TP006.pdf) and [Sydney (Fort Denison)](https://www.bom.gov.au/ntc/IDO59001/IDO59001_2027_NSW_TP007.pdf).
  Times are local (AEST, or AEDT when in effect). Heights are metres above Lowest Astronomical Tide. Each site uses the nearest standard port, so treat times as approximate. Predictions exclude swell and wave run up.

## Sydney Motorsport Park scraper

The SMSP feed is generated from the public Sydney Motorsport Park event calendar:

https://events.sydneymotorsportpark.com.au/eventcalendar/s/

### How it works

1. GitHub Actions runs the scraper daily.
2. Playwright opens the dynamically rendered SMSP calendar.
3. The scraper extracts event data from structured data and rendered event links.
4. It writes:
   * `docs/calendar.ics`
   * `docs/events.json`
   * `docs/debug.json`

The workflow only commits those three files. It never touches the hand built calendars.

### Run manually

Open **Actions → Update Sydney Motorsport Park calendar → Run workflow**.

### Diagnostics

If the scraper fails to discover events, inspect `docs/debug.json`.
It records a preview of the rendered page, candidate event links, and a limited sample of JSON responses captured while the page loads.

### Notes

* Timed SMSP events use `Australia/Sydney`.
* Stable event UIDs are generated from event URLs, so normal updates do not create duplicates.
* All day events use date values.
